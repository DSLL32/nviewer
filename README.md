# nviewer

nviewer is a slop coded level viewer for Nintendo 64 games, and a repository of
slop written reverse engineered technical specs of various games.

- [Open the viewer](https://dsll32.github.io/nviewer/)
- [Read the generated specification wiki](https://dsll32.github.io/nviewer/wiki/)

The full project documentation is in [README-FULL.md](README-FULL.md).
